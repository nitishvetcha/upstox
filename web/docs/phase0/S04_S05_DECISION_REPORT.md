## 1. Current production implementation
- Spread: long call at delta +0.5 (CE; put equivalent), short call at long strike + width.
- Width = ceil(daily ATR / strike step) × strike step (`strategy.ts` `wingWidth`). Ties width to daily range (S-05).
- Entry debit = long mid − short mid. Max profit = width − debit. Max loss = debit (before costs).
- Stop = 0.5 × debit. Target 1 = debit + 0.5 × max profit. Target 2 = debit + 0.8 × max profit.
- Plan reward-to-risk = max profit / debit (gross, no costs). The risk module checks net reward-to-risk after costs separately.

**Hard-coded constants:** stop 0.5; target 1 factor 0.5; target 2 factor 0.8; width rule. None is derived in the documentation.

## 2. Documented formula
The documented formulas cover long options only (move = |delta| × ATR; stop and targets from that move). The spread stop and targets are not documented, so there is no documented formula to compare against. This is part of S-04 and S-05.

## 3. Mathematical explanation
Spread value V(S, σ, t) = C(S, K1, σ, t) − C(S, K2, σ, t). Debit D = V at entry. A stop or target is a level on V. P&L per unit = V_exit − D − costs. Both legs must be repriced, since one leg's premium change is not the spread's P&L.

## 4. Candidate formulas
- **Stop:** S0 current (0.5 D); S1 fixed 0.3 D; S2 fixed 0.7 D; S3 scenario-based (spread value at −1 ATR, IV and time held).
- **Target:** T0 current (D + 0.5 × max profit); T1 (D + 0.8 × max profit); T2 scenario-based (spread value at +1 ATR).

## 6. Failure cases and a method bias (critical)
- **Terminal-value bias:** the test checks the spread value only at the end of each scenario. A stop touched intraday and recovered before the end is never counted. Tight stops therefore look better than they are. S2 (tightest stop) ranks first for this reason. **Its ranking is an artefact and must not be used to select a formula.**
- **Theta-only stop-outs:** with no move and one day passing, the 50% stop can fire on decay alone.
- **Plan reward-to-risk is gross.** After costs it falls (current 1.66 → 1.58 base, 1.32 stress for T0).
- **Width depends on daily ATR:** a volatile day means a wide spread and a larger debit, which lowers the reward-to-risk.
- **Scenario stops depend on the volatility assumption:** if real IV differs, the stop level is wrong.
- **Targets rarely fill:** T1 (0.8 of max profit) is hit in 0–7% of scenarios; its mean comes from end-of-scenario marks, not from target fills.

## 7. Recommended research candidate and reasons

- **Next research step (offline):** replace the terminal test with a path simulation (underlying and IV paths across the session, with intraday stop and target touches checked at each step), then re-run the same candidates under the three cost scenarios.
- **Provisional research candidate:** a scenario-based stop and target from full two-leg repricing, evaluated by path simulation. It is the most interpretable option, and it ties exits to a stated move and to IV, rather than to a fixed fraction of debit.
